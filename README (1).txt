GitHub Repo Viewer

Pàgina web feta amb Bootstrap i jQuery.

Què fa:
- Demana un nom d'usuari de GitHub.
- Busca els seus repositoris amb l'API de GitHub.
- Mostra una taula amb el nom, la descripció i els seguidors (estrelles) de cada repositori.

Com provar-la: obre el fitxer index.html amb el navegador.
